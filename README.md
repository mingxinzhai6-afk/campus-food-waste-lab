# 一餐之后 · 微信小程序版（横屏）

校园食物浪费可视化行动实验室的微信小程序移植版，由同目录 `source_extract/p1-meal-after` 的 React + Vite + ECharts Web 版移植而来。**锁定横屏**（`pageOrientation: "landscape"`）：手机打开即以宽屏多栏版式 + 左侧导航栏展示；同一套页面与数据同时保留了竖屏（逻辑宽度 <731px）时的底部导航条 + 单列布局作为回退。导航栏与内容已适配刘海屏安全区（`env(safe-area-inset-*)`），横屏时左侧导航不会被刘海压住。

## 如何运行

1. 打开微信开发者工具 →「导入项目」→ 选择本目录（`yican-miniprogram`）。
2. `project.config.json` 里的 AppID 当前填的是本机登录账号的**测试号**（`wx3b241972b197922e`，从开发者工具自带示例项目中取得）；换成自己的 AppID 或在导入时选「测试号」即可。
3. 基础库建议 ≥ 2.25（开发用了 slider、chooseMedia、离屏 canvas 做图像压缩与识别）。

无需 npm install，无第三方依赖；`node_modules` 不存在，页面上的图表与插画全部用 CSS / 内联 SVG（data URI）绘制，不用 canvas。

## 与 Web 版的差异（取舍说明）

- **背景音乐被移除**：原 `Left_on_the_Tray.mp3` 有 2.5MB，放不进 2MB 主包（图片压缩后整个包 0.98MB）。如需恢复：把 mp3 压到 ≤1MB 放入 `audio/`，在 `app.js` 用 `wx.createInnerAudioContext` 循环播放即可。
- **点阵粒子背景 / 早晚色调**等纯装饰层未移植，保留手绘纸感主题（配色、不规则圆角、纸影与描边与 Web 版同一套 tokens）。
- **餐厅 3D 旋转门**改为三张餐厅卡片（竖屏纵向叠放、横屏并排），交互等价。
- **打卡照片识别**（`utils/vision.js`）与 Web 版 `foodVision.ts` 逐条对应：亮度 / 饱和度 / 色温（暖光自适应关闭）/ 表面起伏四判据，只统计画面中心圆，结果可手动修正；仍不是训练出来的模型。

## 数据与口径（与 Web 版一致，可复算）

- 数据集中在 `utils/data.js`：三食堂菜单（portionG）、12 条样本记录、系数（35L 水 / 1.8kg CO₂e / 4.2 元每 kg、平均一份 0.32kg）。
- 记录页「一份」按所选食物类别由菜单分量现场推算（`portionKgFor`）；校园看板泔水量由「演示时间」按早/午/晚时段推算（`wasteAtTime`）；策略减损率叠加封顶 80%。
- 全部为演示用示例值，非学校官方统计。

## 在真机上使用 / 上线前清单

1. **换 AppID**：`project.config.json` 里的 `appid` 需要换成你自己的——最快的办法是用官方「小程序测试号」（[申请入口](https://mp.weixin.qq.com/wxamp/sandbox?doc=1)，微信扫码即得、免实名），或注册一个正式的个人小程序。**不换 AppID，微信会拒绝预览（"登录用户不是该小程序的开发者"）**。
2. **自己先玩（预览）**：开发者工具里点「预览」，用同一个微信扫二维码即可在手机上体验（相机拍照、相册保存都是真机能力）。预览二维码有效期约 25–30 分钟，过期重新点一次。
3. **隐私保护指引**：真机上调用拍照 / 选图（`wx.chooseMedia`）与保存到相册（`wx.saveImageToPhotosAlbum`）前，需要在 `mp.weixin.qq.com` 后台配置《小程序用户隐私保护指引》，勾选「摄像头」「相册（仅写入）」并写明用途（拍照打卡 / 保存行动卡）；否则真机上这些接口会被微信拒绝。
4. **让别人也能玩**（需要**正式的个人小程序 AppID**；测试号只能自己预览，不能上传、不能设体验版）：
   - **体验版（最快，不用审核）**：工具里「上传」→ 填版本号（如 1.0.0）→ 到 `mp.weixin.qq.com` → 管理 → **版本管理** → 把该开发版本设为「体验版」→ 把体验二维码发给对方。对方需先被加为**体验成员**（成员管理 → 体验成员；个人主体上限约 10–15 人，以后台显示为准），扫码即可使用。**没被加为体验成员的人扫体验码会提示无权限**，转发小程序卡片同理。
   - **正式发布（任何人扫码即可玩）**：版本管理 → 提交审核（需先完善名称、头像、服务类目、隐私指引；审核通常 1–7 天，可能被驳回）→ 审核通过后点「发布」。之后任何微信扫码/搜索都能打开，不再受成员限制。
5. 名称、头像、服务类目在公众平台后台设置，不在代码里。

## 页面间跳转

五个主页面通过 `getApp().go(id)`（`wx.redirectTo`）互切，像 tab 一样不堆叠页面栈；共享状态（选中的餐厅、时段、食物、剩余比例、策略）放在 `app.globalData`，返回上一页时状态保留。

## 已知限制

- 真机首次打开打卡页会请求相册权限（保存行动卡时）；拒绝后只提示，不影响其他功能。
- 打卡记录保存在本机（用户目录 + storage），删除小程序即清空——与 Web 版 localStorage 同一口径。
- 宽屏 / 横屏（≥731px，横屏锁定时即此形态）为原来的多栏版式 + 左侧导航栏；逻辑宽度 <731px 时回退为单列 + 底部导航条：多栏面板按先后顺序纵向排列，两张表格列距收窄后仍可完整阅读。
